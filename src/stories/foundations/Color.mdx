# Color

Source of truth: **KLA Vivid Electric, Option 3**, WCAG 2.2 / ADA 508 audited.
Product-specific scales (Machine State, Alarm Severity) are re-keyed to these
same tokens so meaning stays consistent app-wide — see
[Token Architecture](/?path=/docs/foundations-token-architecture--docs) for
the tier these live in. All swatches below render the live token, not a
hardcoded color chip.

## Usage guidelines

| Token | Use for | Never for |
|---|---|---|
| `action` | Primary buttons, active nav, links, focus rings, selected rows | Status/severity meaning |
| `accent` | Secondary chart series, highlights, badges distinct from Action | Primary CTAs — reserved for Action |
| `success` | Completed/executed states, positive trend, confirmation | Decorative accents unrelated to a positive outcome |
| `warning` | Pending states, non-fatal alarms, caution banners | Critical or blocking errors — use Error instead |
| `error` | Fatal alarms, failed operations, destructive confirmation | Warnings that are recoverable |
| `info` | Neutral banners, data-integrity category, tooltips | Anything requiring user action |
| `neutral` | Disabled state, secondary text, dividers, unselected chips | Any semantic or interactive meaning |

  <p style="font-size:13px;color:var(--color-ink-600);margin:6px 0 0;">Text on a tinted background must hit 4.5:1. Use the full-strength token for text/icon, the tint only for fill behind it.
