# Density & Themes

Every token on this page — foundations through patterns — is meant to
re-point live from a single theme switch, since nothing in the system is a
separate "dark mode stylesheet": it's the same semantic tokens (tier 2,
see [Token Architecture](/?path=/docs/foundations-token-architecture--docs))
resolving to different primitive values. **This pass implements Light only**;
Dark and High Contrast are specified below so the next pass has an exact
target, but neither is wired up yet — there is no theme switcher in this
build.

## Themes

| Theme | Status | When | Key differences from Light |
|---|---|---|---|
| **Light** | ✅ Implemented (this pass) | Default for all FleetPack modules | — |
| **Dark** | Specified, not yet implemented | Opt-in, persisted per user; recommended for 24×7 NOC / control-room monitors | Semantic surfaces invert; brand hues shift lighter to hold contrast on dark backgrounds; shadows lose color tint (see [Radius & Elevation](/?path=/docs/foundations-radius---elevation--docs)) |
| **High contrast** | Specified, not yet implemented | System-level HC mode, or manual opt-in for FAB glare / accessibility needs | Tints become solid white, borders go pure black at 1–2px heavier weight, shadows removed in favor of borders, focus ring widens to 3px; radius values stay identical (see [Radius & Elevation](/?path=/docs/foundations-radius---elevation--docs)) |

  <strong style="font-size:12px;color:var(--color-action-hover);">Why Dark and High Contrast aren't a rewrite</strong>
  <p style="font-size:13px;color:var(--color-ink-600);margin:6px 0 0;">Because components only ever reference tier-2 semantic tokens (<code>--color-action</code>, <code>--color-neutral-200</code>, …), landing both themes later is a matter of redefining that one tier per theme — attaching alternate values under a <code>[data-theme="dark"]</code>/<code>[data-theme="hc"]</code> selector — not touching component CSS. That's the whole reason the primitive/semantic split in <a href="/?path=/docs/foundations-token-architecture--docs">Token Architecture</a> exists.</p>
