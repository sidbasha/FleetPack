# Typography

Three families, one job each: **Instrument Sans** carries personality on
headings only, **Inter** stays neutral and dense for all UI text,
**JetBrains Mono** marks anything literal — IDs, code, hex values, file
paths. Every sample below is rendered with the live `text-*` utility, not a
screenshot.

## Rules

All numeric table and KPI values use `font-variant-numeric: tabular-nums` (the
`.mono-data` utility class, or `tabular-nums` directly) so columns of digits
align. Percentages always show one decimal (`98.2%`), hours show one decimal
(`120.4h`). Single-line labels truncate with an ellipsis at the container edge
and always carry a native `title` tooltip with the full value — tool and
fleet names are never silently cut.

| ✅ Do | ❌ Don't |
|---|---|
| Use Instrument Sans (`font-display`) only for headings (h1–h4) and hero numerals. Keep all UI copy in Inter (`font-sans`, the default). | Set body paragraphs or table cells in Instrument Sans — it was drawn for short display strings, not dense reading. |
