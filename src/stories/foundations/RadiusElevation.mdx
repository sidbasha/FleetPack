# Surfaces, Radius & Elevation

Four background surfaces, five radii, three border weights and five
elevations. Together they answer one question: what is this thing sitting
on, and how far off the page is it? Elevation encodes distance, not
importance — a card that matters more doesn't float higher, it gets a
heavier border or an accent rail instead.

## Background surfaces

Every background in FleetPack is one of these role aliases, not a raw
neutral step picked by eye.

| Container | Background | Separation | Rule |
|---|---|---|---|
| Page | `--surface-page` | None | Never white |
| Panel / card | `--surface-card` | 1px border + e1 | The default container |
| Well inside a card | `--surface-sunken` | No border, no shadow | Code blocks, nested table rows, empty-state interiors |
| Table header | `--surface-sunken` | 1px bottom rule | Sticky headers gain a rule on scroll, never a shadow — a shadow over data reads as a bug |
| Menu / popover | `--surface-raised` | 1px border + e3 | Floats over content, so it earns a real shadow and a border for the high-contrast theme |
| Modal / drawer | `--surface-card` | e4 + scrim | The scrim, not the shadow, is what separates it from the page |

**Border, shadow, or tone — pick one per edge.** Border is the default. Shadow
only when the container floats above the page and can be dismissed (menus,
popovers, toasts, overlays). Tone is for recession inside an existing
container, where a second border would create a double rule against the
parent edge. Stacking more than one of the three on the same edge is a sign
the boundary is trying to say too much at once.
